Strona główna

Przygotowanie do kursu AI dla programistów

Pięć dni · 09:00-16:00 czasu polskiego. Spotykamy się na żywo w Zoom. Pracujesz na maszynie VM z Windows Server zapewnionej przez organizatora, a aplikację do obsługi zwrotów i reklamacji elektroniki rozwijamy na podstawie wspólnego PRD lub własnego pomysłu.

Program szkolenia · 5 dni · Główne ćwiczenie · Wszystkie materiały

Przed szkoleniem: sprawdź punkty 01-04. Narzędzia na VM sprawdzimy razem na początku pierwszego dnia.

01 / Zoom

Połączenie na żywo

Sprawdź: link do Zooma z zaproszenia organizatora. Dołącz około 08:45-08:50, aby sprawdzić dźwięk i obraz przed startem o 09:00.

Gdy nie działa: skontaktuj się z organizatorem i zgłoś problem z dostępem do spotkania.

02 / Pulpit zdalny

Połączenie z maszyną VM

Sprawdź: klienta Pulpitu zdalnego na swoim komputerze. W Windows użyj wbudowanej aplikacji Pulpit zdalny; pomoc znajdziesz w instrukcji Klienci Pulpitu zdalnego. W Linuksie możesz użyć Remminy.

Dostęp: dane do VM otrzymasz od organizatora. Zachowaj je poza materiałami kursu; gdy połączenie nie działa, zgłoś to organizatorowi.

03 / GitHub

Konto i repozytorium kursu

Sprawdź: czy możesz zalogować się na konto GitHub i otworzyć repozytorium kursu. Git na VM jest już przygotowany przez organizatora.

Gdy nie działa: zgłoś brak dostępu do repozytorium prowadzącemu.

04 / konta AI

Codex i Claude Code

Przygotuj: firmowe konto ChatGPT/Codex. Na VM zalogujesz się pierwszego dnia razem z grupą. Jeśli masz Claude Pro lub Max, przygotuj też to konto - przyda się do pracy w Claude Code.

Gdy nie działa: zgłoś problem z kontem prowadzącemu podczas konfiguracji.

05 / na VM · zapewnia organizator

Narzędzia do pracy na zajęciach

Sprawdzimy razem pierwszego dnia: Codex CLI, Claude Code, VS Code, Git i Node.js. Nie musisz instalować ich na własnym komputerze przed kursem.

06 / po kursie · polecane

Praca na własnym komputerze

Po kursie możesz przygotować lokalne środowisko: Codex CLI, Claude Code i Git. To przyda się do dalszej praktyki, ale nie jest warunkiem udziału w szkoleniu.
