# Delegation Protocol

Use with **one supplied task-registry row, one packet and selected source excerpts**. Do not read the full index, other packets, full PRD or all ADRs by default.

## Context contract

PRD is functional authority; ADRs are technical authority; design guidelines are visual authority. The plan governs order/ownership/context only. Heading links and AC/TAC identifiers are selectors, not whole-file read instructions.

The manager loads the index and current packet, confirms accepted dependencies, then supplies: role, registry row, base commit/artifact versions, exclusive paths, packet, this protocol, applicable AGENTS instructions and necessary canonical excerpts. Include complete relevant DTO/error/terminal definitions, algorithm constraints and actual source/test files; a tiny incomplete brief is not optimization. Send artifact links, not whole prior reports. Full selected policy remains runtime application input, not general agent background.

Prefer fresh no-history specialists for independent work; reuse only closely related context, because a shorter follow-up does not erase history, and start a fresh thread/session if bloated history and runtime support warrant it. Aim for 1–3k tokens of task-specific input, a soft budget. Fetch necessary missing sections incrementally and explain any whole-file/large read. Query scoped current Context7 documentation only for APIs needed, using ADR IDs. Do not inspect course-materials.

**Copy-ready assignment:**

> Role: be-developer. Task: B06; supplied index row: [exact row]. Base: [accepted SHA]; upstream contracts/resources/routes: [paths + revisions]. Exclusive files: [B06 packet paths]. Read B06 + this protocol; receive PRD AC-04–07/10–13/19/21–23 and §11.4–11.5, ADR-002 Image Analysis/Form and Prepared Image/POST /api/analysis/AI Calls and Current API Selection/Error Mapping/Deadlines, Retry and Concurrency excerpts. Inspect relevant accepted source/imports; report missing context rather than guessing.

Routine choices follow specifications/defaults. Report genuine blockers with evidence to the orchestrator, not directly to the user.

## Shared-root execution

The manager does not implement or mutate Git. Specialists edit disjoint leased files in one repository, without worktrees. BE owns explicit staging/commits. Freeze **all writers** for changed-scope verification, independent manual QA and commit. Use only committed dependencies or explicitly accepted current-task files; do not rely on unrelated unfinished work. If it breaks checks/startup, defer; never revert/stash/secretly stage it. Preserve user edits/configuration and secrets.

One port-3000 lease identifies the matching real server/process; stop only its owner’s process. QA owns paired browser tests before product behavior; healthy red evidence precedes implementation. Accepted QA tests and production changes enter one green feature commit. R checkpoints are not red-only completed tasks. Native roles inherit settings; verify callable names, use the index fallback only if unavailable.

Private server modules require server-only boundaries; shared contracts stay client-safe.

## Verification once

Behavior: specification → meaningful failing assertion → minimum green → scoped checks → separate manual QA → focused commit. Missing imports/credentials/broken runners are not behavioral red. Bootstrap establishes a healthy harness first; docs/test-only acceptance need no fabricated failure. Early private backend work verifies real shell/import boundaries; invoke actual routes when available without diagnostic UI.

U/I run exact owned tests via ADR-001 scripts; CHECK = lint/typecheck/build; LIVE = scoped real E2E; MANUAL = independent Playwright CLI. Unit collaborators may be replaced. Integration replaces **only external LLM HTTP**. E2E mocks **nothing**, including network/services/models/storage/history; actual OpenRouter generations are required. Missing key/quota/network/fixtures fails, never skip-green.

Runtime commits require real startup and separate CLI exercise of available changed flow. UI changes capture every affected screen at 360/1440, check Polish/keyboard/console and compare Allegro screenshots/tokens. Full journeys run when available. Automated E2E is not manual QA. Reuse current evidence only when unaffected; capacity selection/reuse is in Q07/Q08.

Use authorized process credentials without exposing/copying secrets. Evidence under ignored `app/verification-output/<ID>/<run>/` records red/green, manual verdict and actual generation IDs. Logs/reports exclude keys, full prompts, raw image payloads/data URLs and full message dumps; approved demo-case screenshots are required. S00 creates no app artifacts.

**Return:** ID/verdict, changed paths, accepted revision, evidence paths, actual-generation verdict, verified commit and blockers; no pasted logs. The manager keeps the concise ledger. No push without explicit user authorization.
