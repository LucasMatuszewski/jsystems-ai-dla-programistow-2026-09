## Use in the PoC

Use the complete linked section as the return scenario's policy context, not this reference alone. It covers eligibility, exceptions, notification and shipment deadlines, packaging, reimbursement and international returns. Preserve qualifications, footnotes, tables and links. The source includes comparisons with complaint-related reimbursements; these do not change the selected scenario.

Return eligibility and suitability for resale are separate assessments. The source allows reimbursement reductions for damage or use beyond necessary inspection; these conditions must not become an automatic refusal of withdrawal.

Apply the Polish marketplace provisions only. Do not assume unknown seller-specific terms or the date of a customer's withdrawal notice. Ask for missing information. Do not load the separate complaint policy into a return conversation.

This is a dated snapshot, not an automatic policy-update service. Linked external pages and offer-specific terms have not been downloaded recursively. Missing applicable terms require clarification or human review.
