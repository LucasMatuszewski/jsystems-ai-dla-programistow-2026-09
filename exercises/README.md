# Ćwiczenie zapasowe: zadania i przykładowy plan czasu

Ta mapa dotyczy wyłącznie syntetycznego laboratorium ze zgłoszeniami. Główna praca grupy to aplikacja do obsługi zwrotów i reklamacji elektroniki lub własny projekt uczestnika, oparty na uzgodnionym PRD. Poniższy plan jest wariantem zapasowym, a nie opisem faktycznego przebiegu szkolenia. Jeśli prowadzący go wybierze, pracuj w ścieżce Python **albo** JavaScript. Może pokazać ten sam kontrakt w obu językach. Moduły D1 i D2 odnoszą się wtedy do [opisu problemu](../docs/problem-brief.md).
